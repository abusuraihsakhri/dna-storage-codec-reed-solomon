Format DSR1: two parity bytes per block of up to 253 data bytes (RS over GF(256)). Can correct one unknown erroneous byte in each block; multiple errors can be detected but are not guaranteed recoverable. Each two-bit symbol maps to a dinucleotide, giving exactly 50% GC and no runs above two bases. This is not a fountain code and does not model sequencing or synthesis errors.
